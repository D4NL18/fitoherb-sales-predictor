# Dicionário de Domínio (Ubiquitous Language)

Este documento mapeia todas as entidades, conceitos e terminologias de negócio do sistema. 
Todos os agentes (Analista, Arquiteto, Desenvolvedor, Reviewer, Tester) devem utilizar estritamente a nomenclatura descrita aqui em códigos, rotas de API, tabelas de banco de dados e comunicação.

## Termos
- **[Exemplo: Cliente]**: Pessoa física ou jurídica que adquire produtos. (Não utilizar "User", "Subscriber" no código que reflete esta entidade, usar sempre "Cliente" / "Client").
- *(O Analista e o Arquiteto deverão popular este documento conforme os requisitos forem sendo especificados).*
